# Photo Gallery

A responsive, lightweight photo gallery built with vanilla HTML, CSS, and JavaScript. Features a clean grid layout with modal lightbox functionality for viewing images in full-screen.

## Features

- **Responsive Grid Layout**: Automatically adjusts to different screen sizes
- **Lightbox Modal**: Click any image to view it in a full-screen overlay
- **Keyboard Navigation**: Press Escape to close the lightbox
- **Smooth Animations**: Hover effects and fade-in transitions
- **Mobile-Friendly**: Touch-optimized interface
- **No Dependencies**: Pure vanilla web technologies

## Tech Stack

- **HTML5**: Semantic markup with accessibility in mind
- **CSS3**: Grid layout, flexbox, transitions, and animations
- **Vanilla JavaScript**: No frameworks, pure DOM manipulation
- **Responsive Design**: Mobile-first approach

## Setup Instructions

1. Clone or download this repository
2. Add your images to the `assets/images/` folder
3. Update the image paths in `index.html` to match your files
4. Open `index.html` in your web browser

### Adding Your Own Images

1. Place your images in the `assets/images/` folder
2. Update the `src` attributes in the `<img>` tags in `index.html`
3. Modify the `<figcaption>` text to add your own captions

## Usage

- **View Gallery**: Open `index.html` in any modern web browser
- **View Full-Size**: Click on any image to open it in the lightbox
- **Close Lightbox**: Click the X button, click outside the image, or press Escape
- **Navigate**: Use mouse or touch to interact with the gallery
